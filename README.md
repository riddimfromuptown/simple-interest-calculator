# Simple Interest Calculator

A simple Bash script that calculates simple interest based on the principal amount, annual interest rate, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## How to Run

1. Open a terminal.
2. Navigate to the folder containing `simple-interest.sh`.
3. Run:

   `bash simple-interest.sh`

4. Enter the principal, annual interest rate, and time when prompted.

## Example

For a principal of 1000, an annual rate of 5, and a time period of 2 years:

Simple Interest = 100

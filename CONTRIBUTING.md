# Contributing Guidelines

Thank you for your interest in contributing to the Simple Interest Calculator project!

## How to Contribute

1. Fork this repository.
2. Clone your fork to your computer.
3. Create a new branch for your changes.
4. Make your changes and test them.
5. Commit your changes with a clear commit message.
6. Push your branch to your fork.
7. Open a pull request describing your changes.

## Guidelines

- Keep the code simple and easy to understand.
- Test your changes before submitting them.
- Write clear commit messages.
- Be respectful and constructive when communicating.

## Reporting Issues

If you find a bug or have a suggestion, open an issue and provide as much detail as possible.

Thank you for helping improve this project!
